01 / A base

As peças que fazem tudo funcionar.

Cada conceito resolve uma parte da colaboração. Juntos, eles criam um fluxo claro para qualquer equipe.

01

Repositório

A casa do seu projeto. Guarda arquivos, histórico de alterações, documentação e as regras para colaborar.

02

Commit

Um registro pontual de mudança. Bons commits contam o que foi feito e deixam o histórico fácil de entender.

03

Branch

Uma linha de trabalho independente. Crie, experimente e corrija sem afetar a versão principal.

04

Pull Request

O convite para revisar e integrar uma mudança. É onde o time conversa antes do código entrar na base.

05

Issue

Um espaço para organizar tarefas, bugs e ideias. Transforme conversas soltas em trabalho rastreável.

06

GitHub Actions

Automação dentro do repositório: testes, builds e deploys que acontecem sempre que algo muda.

02 / Na prática

Da ideia ao código integrado.

Um fluxo simples transforma colaboração em hábito. O time sabe onde começar, onde revisar e quando entregar.

01

Clone o repositório

Traga uma cópia do projeto para sua máquina e prepare o ambiente local.

02

Crie uma branch

Separe seu trabalho com um nome que explique a tarefa: feature/perfil.

03

Faça commits claros

Salve pequenas mudanças com mensagens objetivas e fáceis de localizar.

04

Abra um Pull Request

Peça feedback, revise os arquivos e integre a solução quando estiver pronta.

03 / Para consultar

Um vocabulário para não travar.

ForkCópia de um repositório na sua conta para propor mudanças em outro projeto.
MergeAção de unir o conteúdo de duas branches em uma só.
RemoteEndereço que conecta seu projeto local ao repositório hospedado.
READMEDocumento de entrada que explica o propósito e o uso do projeto.
ReviewLeitura colaborativa do código para encontrar melhorias antes da integração.
DeployPublicação do código em um ambiente onde outras pessoas podem acessá-lo.
